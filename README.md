## Deskripsi

Program ini dibuat untuk mempelajari penggunaan list dalam Python, mulai dari membuat list, mengakses elemen, melakukan slicing, memanipulasi data, menghitung statistik, hingga menganalisis nilai mahasiswa.

## Daftar Program

1. `01_buat_list.py` - Membuat dan menampilkan list.
2. `02_indeks_slicing.py` - Mengakses elemen menggunakan indeks dan slicing.
3. `03_manipulasi_list.py` - Menambah, menghapus, dan mengurutkan elemen list.
4. `04_agregasi_nilai.py` - Menghitung jumlah, rata-rata, nilai tertinggi, dan nilai terendah.
5. `05_filter_kelulusan.py` - Memisahkan nilai yang memenuhi batas kelulusan.
6. `06_fungsi_statistik.py` - Menggunakan fungsi untuk menghitung statistik.
7. `praktik/analisis_nilai_mahasiswa.py` - Menganalisis nilai mahasiswa dan status kelulusan.

## Cara Menjalankan

1. Buka folder proyek di Visual Studio Code.
2. Pastikan Python sudah terpasang.
3. Buka file Python yang ingin dijalankan.
4. Jalankan melalui tombol Run Python File atau terminal.

Contoh perintah:

```bash
python latihan/01_buat_list.py
```
